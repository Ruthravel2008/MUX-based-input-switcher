    Concept

    Learn About Multiplexers

    A MUX is a data selector. Everything else on this page is built on that one idea.

    What is a MUX?

    A Multiplexer is a combinational circuit that selects one input from multiple inputs and forwards it to a single output based on select lines.

    Think of a TV input switch: HDMI 1, 2, 3 and 4 are all connected, but the screen shows only the one you pick. Because the circuit has no memory, the output changes as soon as the select lines change.

    • Combinational: output depends only on the present inputs
    • Many data inputs, one output
    • Select lines choose which input is forwarded

    System architecture

    1. 🙋

      User

      Chooses a feature set by setting the select lines.

    2. 🎚️

      Selector (S1, S0)

      Two binary control signals: 00, 01, 10 or 11.

    3. ⚡

      4:1 Multiplexer

      Enables exactly one AND path and ORs the result into Y.

    4. 🧩

      Selected feature set

      Basic, Statistical, Behavioral or Advanced features.

    5. 🤖

      Model

      Simulated classifier that processes the selected features.

    6. 📈

      Performance metrics

      Accuracy, precision, recall, F1 score and processing time.

      About the Project

      EC2201 Digital Systems · Unit II – Combinational Circuits.

      Project title

      MUX-Based Model Input Switcher: an interactive digital-systems laboratory that uses a 4:1 multiplexer to choose which feature set feeds a simulated model.

      Problem statement

      A model can be fed several alternative feature sets, but only one can be connected to it at a time. We need a clear way to switch between them and compare the effect on model quality and speed.

      Objective

      Demonstrate a 4:1 MUX (inputs, select lines, single output, Boolean expression, truth table) and use it as the input switch of a model pipeline, with an automated test suite and a performance comparison.

      MUX concept

      Y = S1′S0′I0 + S1′S0I1 + S1S0′I2 + S1S0I3. The select lines decode into four AND-enabled paths; exactly one is open and the OR gate passes it to Y. With n select lines a MUX has 2ⁿ inputs.

      Real-world application

      Data-processing systems constantly choose one source among many: sensor selection in IoT gateways, camera or channel selection in edge-AI devices, and feature-set selection in ML pipelines.

      Technology stack

      • HTML5
      • CSS3
      • Vanilla JavaScript
      • SVG
      • IntersectionObserver
      • localStorage

      No frameworks, no external libraries, no network needed. Works from a double-click or python -m http.server.

      Synthetic dataset

      Scenario: predicting subscriber churn. Feature names, sample vectors and metrics are synthetic and fixed (seeded generator, seed 2201), so the same run gives the same numbers every time. They are not results of a real experiment.

      Testing methodology

      18 automated cases: 10 normal (each selector, single-bit data, distinct feature sets) and 8 edge / fault (all 0, all 1, one-hot data, 1000 rapid changes, missing inputs, missing or invalid selectors, missing feature data).

      Expected output

      • 00 → I0, 01 → I1, 10 → I2, 11 → I3
      • Model metrics update for the selected feature set
      • Test Lab: 18 / 18 tests passed
